# Pranit Mandlik Portfolio — Enhanced Version

A static, premium developer portfolio built using:
- HTML
- CSS
- Vanilla JavaScript

Included project visuals:
- Dine-In Management System dashboard
- AUTOVEX predictive maintenance dashboard

Included:
- Responsive premium dark UI
- Animated scroll reveals
- Technology marquee
- Interactive project image fullscreen viewer
- Resume link
- GitHub + LinkedIn links
- Email-only contact CTA
- Project feature chips and technology stacks
- Responsive mobile navigation
- Open Graph metadata

No Node.js, backend, database, or build step is required.

## Local preview
Open `index.html` directly in a browser or use VS Code Live Server.

## Vercel
Import the repository in Vercel. This is a static site, so no Node.js server or build command is needed.
